# jim-coil-rewrite

Native Coil rewrite of Jim Editor. Initial shell: independent project canvases,
movable Ghostty terminal panes, Compiz-style project overview, and live Coil
configuration. Pan/zoom behavior follows the original Jim input handler.

Project index and findings: [jim-coil-rewrite](pad://jim-coil-rewrite).
See README.md for running and controls, and docs/architecture.md for boundaries.
